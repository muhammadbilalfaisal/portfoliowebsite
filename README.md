# BilalHustle Portfolio

A responsive portfolio website presenting selected web development, business systems, e-commerce, and automation work.

## Built with

- React
- Vite
- JavaScript
- CSS
- Framer Motion
- Lucide React

## Local development

Requires a current Node.js LTS release.

```bash
npm install
npm run dev
```

Vite will display the local development URL in the terminal.

## Commands

```bash
npm run dev      # Start the development server
npm run build    # Create a production build
npm run preview  # Preview the production build
npm run lint     # Run code-quality checks
npm run format   # Format the codebase
```

Run the following checks before publishing changes:

```bash
npm run lint
npm run build
```

## Project structure

```text
src/components/   Page sections and reusable interface components
src/data/         Public portfolio content
src/hooks/        Shared React hooks
src/styles/       Global and responsive styles
src/utils/        Shared utilities
public/           Public static assets
```

## Accessibility and performance

The site includes responsive layouts, reduced-motion support, semantic page structure, keyboard-accessible navigation, optimized images, lazy-loaded project media, and asynchronous image decoding.

## Security

Environment files, local configuration, build output, logs, and editor settings are excluded from version control. Never commit credentials, private API keys, customer data, or non-public business documents.
